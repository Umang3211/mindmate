# MindMate

A mental health chat companion with an iMessage style interface, built so that talking through a hard day with an AI feels like texting a friend.

**Best Social Good Hack, PantherHack 2024** · [Devpost](https://devpost.com/software/mindmate-eh38gv)

Built with Vivann Khanna and Ankith Namireddy.

## Stack

Next.js 14 · TypeScript · Tailwind CSS · Vercel AI SDK · OpenAI API

## Run it

```bash
npm install
echo "OPENAI_API_KEY=your_key" > .env.local
npm run dev
```

Then open http://localhost:3000.
